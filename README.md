# 🕌 মাদ্রাসা হিসাব

মাদ্রাসার **জমা ও খরচের হিসাব** রাখার মোবাইল অ্যাপ (PWA)।
React + Vite + Supabase দিয়ে বানানো — ফোনের হোম স্ক্রিনে ইনস্টল করা যায়।

> **সবাই দেখবে, শুধু অ্যাডমিন বদলাবে।**
> সাধারণ সদস্যের কোনো লগইন লাগে না — অ্যাপ খুললেই সব হিসাব দেখা যায়।
> অ্যাডমিন আলাদা লগইন করে সব যোগ/বদল/মুছে ফেলবে।

## 🚀 সেটআপ (৫ ধাপ)

### ধাপ ১ — Supabase প্রজেক্ট
[supabase.com](https://supabase.com) → **Start your project** (ফ্রি)

### ধাপ ২ — তিনটা SQL ফাইল চালান (এই ক্রমে)

Supabase → **SQL Editor** → **New query** → কোড পেস্ট → **Run**

| ক্রম | ফাইল | কাজ |
|---|---|---|
| ১ | `supabase/schema.sql` | টেবিল, RLS, ট্রিগার |
| ২ | `supabase/seed.sql` | অক্টোবর ২০২৬-এর আসল হিসাব |
| ৩ | `supabase/public-viewer.sql` | **লগইন ছাড়া পড়ার অনুমতি** (ভিউয়ার মোড) |

> ৩ নম্বরটা না চালালে সাধারণ সদস্য কিছু দেখতে পাবে না।
> প্রতিটা ফাইল বারবার চালালেও ডেটা ডাবল হবে না।

### ধাপ ৩ — অ্যাডমিন অ্যাকাউন্ট বানান

Supabase → **Authentication → Users → Add user → Create new user**

- ইমেইল ও পাসওয়ার্ড দিন
- ✅ **Auto Confirm User** টিক দিন
- এটাই হবে তোমার অ্যাডমিন লগইন

> প্রথম ইউজার স্বয়ংক্রিয়ভাবে **সুপার অ্যাডমিন (owner)** হবে।
> পরে সেটিংস থেকে অন্য সদস্যকে অ্যাডমিন বানাতে পারবে।

**যদি লগইন করার পরও অ্যাডমিন না দেখায়** (আগে কেউ টেস্টে সাইনআপ করে ফেললে এমন হয়):
`supabase/make-admin.sql` ফাইলে তোমার ইমেইল বসিয়ে Supabase → SQL Editor-এ Run করো।
তখনই তোমার রোল `owner` হয়ে যাবে।

**Confirm email বন্ধ রাখতে:** Authentication → Sign In / Providers → Email → *Confirm email* বন্ধ করুন।

### ধাপ ৪ — `.env` ফাইল

প্রজেক্টের রুটে `.env` বানিয়ে Supabase → **Project Settings → API** থেকে কপি করুন:

```
VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

> পুরোনো প্রজেক্ট হলে `VITE_SUPABASE_ANON_KEY=eyJhbGciOi...` দিলেও চলবে।
> ⚠️ **secret key** (`sb_secret_...`) বা **service_role key** কখনো `VITE_` প্রিফিক্স দিয়ে লিখবেন না — সেটা ব্রাউজারে চলে যায়।

### ধাপ ৫ — চালান

```bash
npm install
npm run dev
```

`http://localhost:5173` খুললেই অ্যাপ চলবে (লগইন ছাড়াই)।

## 📱 GitHub → Vercel → Android

### GitHub

```bash
cd madrasa-hisab
git remote add origin https://github.com/USERNAME/madrasa-hisab.git
git push -u origin main
```

> `.env` পুশ হবে না (gitignore-এ আছে) — এটা ইচ্ছাকৃত।

### Vercel (ফ্রি হোস্টিং)

1. [vercel.com](https://vercel.com) → GitHub দিয়ে লগইন
2. **Add New → Project** → repo সিলেক্ট
3. **Environment Variables**:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_PUBLISHABLE_KEY` (অথবা `VITE_SUPABASE_ANON_KEY`)
4. **Deploy**

> Netlify-ও চলবে — Build: `npm run build`, Publish: `dist`

### Android-এ ইনস্টল

1. ফোনের Chrome-এ Vercel লিংক খুলুন
2. **⋮ → Add to Home screen / Install app**
3. হোম স্ক্রিনে আইকন — আসল অ্যাপের মতো চলবে 🎉

## 🔐 নিরাপত্তা

- সব টেবিলে **Row Level Security** চালু
- **পড়া** — সবার জন্য খোলা (এটা ইচ্ছাকৃত, অ্যাপের ডিজাইনই তাই)
- **লেখা** — শুধু লগইন করা `owner` / `admin` / `treasurer`
- নিজে নিজে রোল বাড়ানো যায় না (DB trigger আটকে রাখে)
- `profiles` (কার কী রোল) — শুধু লগইন করা ইউজার দেখে
- ⚠️ কখনো **service_role / secret key** ব্রাউজারে বা Vercel-এর `VITE_` ভেরিয়েবলে দেবেন না

## 🧮 হিসাবের নিয়ম

```
মোট জমা (এই মাস) = বিগত মাসের বহন + নতুন জমা
অবশিষ্ট = মোট জমা − মোট খরচ
```

উদাহরণ (অক্টোবর ২০২৬):
```
বিগত মাসের জমা   ২,৪৯০
নতুন জমা (১৪ জন)  ৩,০০০
সর্বমোট           ৫,৪৯০
হুজুরের বেতন     −২,৫০০
অবশিষ্ট           ২,৯৯০ ✓
```
