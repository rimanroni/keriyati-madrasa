# 🕌 মাদ্রাসা হিসাব

মাদ্রাসার **জমা ও খরচের হিসাব** রাখার মোবাইল অ্যাপ (PWA)।
React + Vite + Supabase দিয়ে বানানো। ফোনের হোম স্ক্রিনে ইনস্টল করা যায়।

---

## ✨ কী কী আছে

**সদস্য (ভিউয়ার) দেখতে পারে**
- মাসিক রিপোর্ট — মোট জমা, মোট খরচ, অবশিষ্ট
- গত ৩ মাসের তুলনা (চার্ট)
- টাকা কোথা থেকে এসেছে / কোথায় খরচ হয়েছে
- জমার তালিকা ও খরচের তালিকা
- নোটিশ বোর্ড
- ❌ সেটিংস নেই (শুধু অ্যাডমিনের জন্য)

**অ্যাডমিন করতে পারে**
- মাদ্রাসার নাম, ঠিকানা, লোগো বদলানো
- 🎨 থিম বদলানো (৫টি) — সবার অ্যাপে বদলে যাবে
- সদস্য তৈরি/সম্পাদনা (নাম, মোবাইল, ছবি)
- জমা ও খরচ যোগ/মুছে ফেলা
- নোটিশ দেওয়া (সবাই দেখবে)
- 💬 WhatsApp-এ ধন্যবাদ/রিমাইন্ডার মেসেজ
- রোল পরিবর্তন + **সুপার অ্যাডমিন হস্তান্তর** 👑
- Excel/CSV এক্সপোর্ট

**রোল:** `সুপার অ্যাডমিন` → `অ্যাডমিন` → `কোষাধ্যক্ষ` → `ভিউয়ার`

## 🚀 ধাপে ধাপে সেটআপ

### ধাপ ১ — Supabase প্রজেক্ট

1. [supabase.com](https://supabase.com) এ যান → **Start your project** (ফ্রি)
2. নতুন প্রজেক্ট খুলুন (নাম যা খুশি, পাসওয়ার্ড সংরক্ষণ করুন)
3. বাম দিকে **SQL Editor** → **New query**
4. `supabase/schema.sql` ফাইলের পুরো কোড কপি করে পেস্ট করুন → **Run**
5. আবার **New query** → `supabase/seed.sql` পেস্ট → **Run**
   (এতে অক্টোবর ২০২৬-এর আসল হিসাব বসে যাবে)

### ধাপ ২ — API Key নিন

Supabase → **Project Settings** → **API** →
- **Project URL** কপি করুন
- **anon public** key কপি করুন

### ধাপ ৩ — `.env` ফাইল

প্রজেক্টের রুটে `.env` নামে ফাইল বানিয়ে লিখুন:

```
VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...
```

> `.env.example` ফাইলটা কপি করে নাম বদলে `.env` করলেও হবে।

### ধাপ ৪ — চালান

```bash
npm install
npm run dev
```

ব্রাউজারে `http://localhost:5173` খুলবে।

### ধাপ ৫ — প্রথম অ্যাকাউন্ট

1. **অ্যাকাউন্ট খুলুন** এ চাপুন → নাম, ইমেইল, পাসওয়ার্ড দিন
2. ⚠️ Supabase → **Authentication → Providers → Email** এ **"Confirm email"** বন্ধ করে দিলে সাথে সাথে লগইন হবে (সহজ)
3. **প্রথম যিনি সাইন-আপ করবেন তিনি স্বয়ংক্রিয়ভাবে সুপার অ্যাডমিন** 👑
4. বাকিরা সাইন-আপ করলে ভিউয়ার হবে — সেটিংস থেকে রোল বদলে দিন

## 📱 GitHub-এ পুশ ও Android-এ ইনস্টল

### GitHub

```bash
git init
git add .
git commit -m "মাদ্রাসা হিসাব অ্যাপ"
git branch -M main
git remote add origin https://github.com/USERNAME/madrasa-hisab.git
git push -u origin main
```

### Vercel দিয়ে ফ্রি হোস্টিং (সবচেয়ে সহজ)

1. [vercel.com](https://vercel.com) → GitHub দিয়ে লগইন
2. **Add New → Project** → তোমার repo সিলেক্ট
3. **Environment Variables** এ যোগ করুন:
   - `VITE_SUPABASE_URL`
   - `VITE_SUPABASE_ANON_KEY`
4. **Deploy** চাপুন → লিংক পাবে (যেমন `madrasa-hisab.vercel.app`)

### Android-এ ইনস্টল

1. ফোনের Chrome-এ Vercel লিংকটা খুলুন
2. উপরে ডান দিকের **⋮** → **Add to Home screen** / **Install app**
3. হোম স্ক্রিনে আইকন আসবে — এবার আসল অ্যাপের মতোই চলবে 🎉

> Netlify-ও ব্যবহার করা যায় — Build command: `npm run build`, Publish directory: `dist`

## 🔐 নিরাপত্তা

- সব টেবিলে **Row Level Security** চালু
- ভিউয়ার শুধু পড়তে পারে, লিখতে পারে না
- নিজে নিজে রোল বাড়ানো যায় না (trigger দিয়ে আটকানো)
- `anon key` পাবলিক হলেও RLS থাকায় ডেটা সুরক্ষিত
- ⚠️ কখনো **service_role key** ব্রাউজারে ব্যবহার করবেন না

## 🧮 হিসাবের নিয়ম

```
মোট জমা (এই মাস) = বিগত মাসের বহন + নতুন জমা
অবশিষ্ট = মোট জমা − মোট খরচ
```

উদাহরণ (অক্টোবর ২০২৬):
```
বিগত মাসের জমা   ২,৪৯০
নতুন জমা (১৪ জন)  ৩,০০০
সর্বমোট           ৫,৪৯০
হুজুরের বেতন     −২,৫০০
অবশিষ্ট           ২,৯৯০ ✓
```
